# 🧩 Glycan Drawing Tool 说明文档

## 📘 简介

**Glycan Drawing Tool** 是一个基于网页的糖链结构绘制与编辑工具。  

用户可以通过可视化界面轻松绘制单糖节点、连接关系以及文字注释，并根据 SNFG（Symbol Nomenclature for Glycans）标准自动生成标准符号表示。交互逻辑与UI界面更加直观，优于现有的其他工具。  

交互逻辑接近ChemDraw，为研究者提供更加一致的使用体验

---

## 🧱 功能概述

界面由四个主要部分组成：

- **左侧面板**：工具栏（选择、添加糖、添加文字、添加预设糖质、橡皮擦）
- **中间画布**：主绘图区域（支持缩放、拖动）
- **右侧面板**：糖形状、颜色、连接样式、文字样式等详细自定义选项
- **顶部面板**：画布操作（撤回/重做、清空画布、导出、画布缩放）

## 🆕 新增功能说明

以下功能已在当前版本中加入，用于提升编辑效率和界面可读性：

- **渲染预设**：每个糖均可选择 **Flat**、**Soft** 或 **Glossy** 渲染效果；多选状态不一致时，渲染按钮保持未按下状态。
- **添加糖模式下的 Linkage 标签页**：可在添加连接前预先设置连接信息、线条样式、文字样式和方向。
- **旋转与排列**：在 View 标签页中可通过罗盘、角度输入或快捷角度按钮旋转；支持对齐、分支微调以及连接长度统一。
- **SVG 剪贴板复制**：使用 `Ctrl+Alt+C` 可将选中的糖、文字和连接直接复制为 SVG，粘贴到 Word、PowerPoint 等软件中。
- **添加模式双击切换**：在添加糖模式下双击已有糖，会自动切换至选择模式并选中该糖。
- **工具快捷键**：`Alt+A` 添加糖、`Alt+T` 添加文字、`Alt+S` 选择、`Alt+P` 预设聚糖、`Alt+D` 删除。
- **访客统计**：左侧面板显示 Busuanzi 页面访问量和访客数，并随中英文语言切换标签。
- **字体与版本显示**：中文界面使用 Noto Sans SC，英文界面使用 Novecento Sans，并提供 Google 字体回退；标题旁显示当前版本号。

## 🎨 添加糖模式

可进行的操作：
- **添加单糖** — 在添加糖模式下，通过点击在画布中添加糖。  
- **定向添加** — 可以通过在已添加的糖上点击或长按并向空白位置拖动，在固定角度添加新糖。  
- **添加键连** — 长按已添加的糖并向另一糖拖动，可以建立两个糖的连接。  
- **自由封端** — 提供自选的自由端表示方法，星号图形将不会导出至图片。
- **预设样式** — 选择模式下可以调节的糖和连接样式（下述）均可在此处预先调整并直接添加。 

---

## 🔧 选择模式

可进行的操作：
- **元素样式调整** — 点击或框选选择糖、键连、文字以对其大小、形状等进行调整或更新。
- **位置移动** — 在选择模式下，拖拽选中的糖可以调整其位置。
- **批量选择** — 框选多个元素进行统一调整、Shift+点击进行精准多选  
- **快捷键支持** — 
  - `Ctrl/Cmd + Z/Y`：撤销/重做  
  - `Ctrl/Cmd + B/I/U`：文字的加粗/斜体/下划线  
  - `Ctrl/Cmd + C/X/V/A`: 复制/剪切/粘贴/全选
  - `Delete / Backspace`：删除选中元素  
  - `Esc`：退出当前模式（如预设放置）

## 🍬 糖结构样式

### 1. SNFG 糖预设
右侧面板提供常见单糖预设（Glc、Gal、Man、GlcNAc、GalNAc、Fuc、GlcA、Neu5Ac、Xyl），符合SNFG 2.0标准，在添加糖模式下预设了样式。 

  - 默认情况下，为了视觉的统一性，预设单糖时**菱形**符号的单糖（GlcA、Neu5Ac）比其他单糖**大** 2 px ，**方形**符号的单糖（GlcNAc、GalNAc）比其他单糖**小** 2 px。但是在选择模式使用预设样式更新已绘制好的糖时不会再改变糖的大小和边缘，只更改填充颜色和形状。 
  - 其他标准单糖可以使用已设置的形状和颜色进行组合，具体请参考左侧面板提供的 SNFG 链接。

### 2. 自定义糖型
可自定义：
- **形状** — 圆、方、菱形、三角形、星形、括号、自由端等。
  - 最后一类形状中的星号 “ * ” 图形不会显示在导出的图片中，可以用于展示一个没有任何连接的自由端；
- **填充颜色与透明度** — 已预设好符合 SNFG 2.0 标准的颜色，也可以使用十六进制 RGB 自定义。
- **尺寸大小**  
- **边缘** — 宽度、样式、颜色、透明度。  

---

## 🔗 连接与Linkage文字

可自定义：
- **Linkage信息** — 输入完整的（如 α2-6）或简化的连接（如 b14）为该键赋予连接形式。
- **Linkage显示** — 勾选即可将linkage信息添加至键右侧，方向符合 SNFG 2.0 标准，数字靠近自由端。通过互换按钮可以反转键连。
- **连接线条样式** — 宽度、样式、颜色、透明度。
- **键连文字样式** — 字号、字体、样式、颜色、透明度。

- 粗体 / 斜体 / 下划线

## 🧩 预设寡糖模板

支持插入预先组件好的完整的糖链 SVG 模板文件，用户点击预设缩略图后，点击画布即可放置模板。

---

## 🧽 橡皮擦

点击或长按进行选择删除或连续删除，支持 Delete / Backspace 快捷键。

---

## 🧮 撤销与重做

内置完整的撤销/重做系统：

- **撤销** — 回退上一步操作  
- **重做** — 恢复被撤销的步骤  
- 最多保存 50 步历史记录  

包括对元素样式变化、位置移动、添加与删除等所有修改。

---

## 🖼️ 导出与画布控制

### 导出选项：
| 格式 | 描述 |
|------|------|
| **SVG** | 可编辑矢量格式，保留全部图形信息 |
| **PNG** | 带透明背景的高分辨率位图 |
| **JPG** | 适合展示的白底位图 |

### 导出尺寸：
- 小（800×600）
- 中（1000×700）
- 大（1200×800）

### 画布操作：
- 拖动：使用鼠标拖动画布
- 缩放：滑块控制 50%–300%
- 重置：恢复至 100%

## 🧑‍💻 技术实现

- **前端框架**：纯原生 JavaScript + SVG 操作  
- **主类结构**：`GlycanDrawer`  
  - 管理画布、事件绑定、元素绘制、撤销重做系统等  
- **核心逻辑模块**：  
  - `setupToolbar()` 工具栏交互  
  - `setupStyleControls()` 样式控制与绑定  
  - `initializeWorkspace()` 初始化画布  
  - `exportCanvas()` 导出逻辑  
  - `handleMouseDown/Move/Up()` 用户交互响应
