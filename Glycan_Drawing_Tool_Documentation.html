🧩 Glycan Drawing Tool 用户说明文档

📘 简介

Glycan Drawing Tool 是一个基于网页的糖链结构绘制与编辑工具。
用户可以通过可视化界面轻松绘制单糖节点、连接关系以及文字注释，并根据 SNFG（Symbol Nomenclature for Glycans）标准自动生成标准符号表示。

该工具特别适合用于科研场景下的糖链结构示意图制作、论文配图和教学展示。

🧱 功能概述

1. 主界面结构

界面由三个主要部分组成：

  • 左侧面板：工具栏（选择、添加糖、添加文字、预设、橡皮擦）
  • 中间画布：主绘图区域（支持缩放、拖动、导出）
  • 右侧面板：糖形状、颜色、连接样式、文字样式等详细自定义选项

🧭 工具栏说明

工具 图标 功能说明
选择 (select) ↖️ 选择已有元素进行移动、复制或样式修改
添加糖 (add) 🍬 在画布中点击放置新的单糖符号
添加文字 (text) 📝 在画布中添加文字注释或标签
预设寡糖 (preset) 🧩 从内置模板中插入完整糖链结构
橡皮擦 (delete) 🧽 删除选中的元素或连续擦除

🎨 糖结构绘制与样式

1. SNFG 糖预设

右侧面板提供常见单糖预设（Glc、Gal、Man、GlcNAc、GalNAc、Fuc、GlcA、Sia、Xyl），
符合 SNFG 2.0 标准，颜色和形状均已自动配置。

2. 自定义糖型

可自定义： - 形状（圆、方、菱形、三角形、星形等） - 边框宽度与不透明度 - 填充颜色与透明度 - 尺寸大小

支持实时更新与撤销/恢复。

🔗 连接与Linkage文字

用户可在糖与糖之间拖动鼠标建立连接（代表糖苷键）。

可设置： - 线条样式（实线、虚线等） - 线条颜色、不透明度、粗细 - 是否显示Linkage文字（如 α1-2、β1-4） - Linkage文字的字体、颜色、透明度

✏️ 文本添加与样式

通过“添加文字”工具可在任意位置插入文本标签。
支持调整： - 字体大小与字体族 - 粗体 / 斜体 / 下划线 - 颜色与透明度

🧩 预设寡糖模板

支持导入和插入完整的糖链 SVG 模板文件（presetGlycanToolbar）。 用户点击预设缩略图后，点击画布即可放置模板。

🧮 撤销与重做

内置完整的撤销/重做系统：

  • 撤销 (Undo)：回退上一步操作
  • 重做 (Redo)：恢复被撤销的步骤
  • 最多保存 50 步历史记录

包括对元素样式变化、位置移动、添加与删除等所有修改。

🖼️ 导出与画布控制

导出选项：

格式 描述
SVG 可编辑矢量格式，保留全部图形信息
PNG 带透明背景的高分辨率位图
JPG 适合展示的白底位图

导出尺寸：

  • 小（800×600）
  • 中（1000×700）
  • 大（1200×800）

画布操作：

  • 拖动：使用鼠标拖动画布
  • 缩放：滑块控制 50%–300%
  • 重置：恢复至 100%

🧰 其他功能

  • 批量选择：框选多个元素进行统一调整
  • 连续擦除：长按橡皮擦可快速删除多个元素
  • 快捷键支持：
    • Ctrl/Cmd + Z：撤销
    • Ctrl/Cmd + Y：重做
    • Delete：删除选中元素
    • Esc：退出当前模式（如预设放置）

🧑‍💻 技术实现

  • 前端框架：纯原生 JavaScript + SVG 操作
  • 主类结构：GlycanDrawer
    • 管理画布、事件绑定、元素绘制、撤销重做系统等
  • 核心逻辑模块：
    • setupToolbar() 工具栏交互
    • setupStyleControls() 样式控制与绑定
    • initializeWorkspace() 初始化画布
    • exportCanvas() 导出逻辑
    • handleMouseDown/Move/Up() 用户交互响应
